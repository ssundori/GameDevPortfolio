
# Swording Over It

> UNIJAM 2023에서 제작한 Unity 2D 게임

## 1. 프로젝트 개요

- **개발 기간:** UNIJAM 2023 01. 06 - 01. 08
- **개발 형태:** 팀 게임잼 프로젝트
- **개발 환경:** Unity 2019.4.34f1, C#
- **담당 역할:** 게임 UI, 설정 화면, 플레이어 피격 및 체력 처리

마우스로 무기를 조작하고 Unity의 2D 물리 시스템을 활용해 캐릭터를 이동시키는 게임입니다.

---

## 2. 담당 구현 기능

### ① 게임 UI 및 체력 표시

- 플레이어의 최대 체력에 따라 체력 UI 생성
- 체력 감소 및 회복 시 UI 애니메이션 변경
- 게임 내 UI 표시 및 상태 관리

**관련 코드**
- `IngameUIManager.cs`
- `Player.cs`

### ② 적 충돌 및 체력 감소

- `OnCollisionStay2D()`를 활용한 적 충돌 감지
- 적과 충돌 시 플레이어 체력 감소 및 넉백 처리
- 피격 후 1초간 추가 피해를 방지하는 무적 시간 적용
- 체력이 0 이하로 감소하면 게임 오버 처리

**관련 코드**
- `Player.cs`

### ③ 일시정지 및 설정 화면

- 게임 일시정지 및 재개 기능
- 설정 패널 열기 및 닫기
- 게임 재시작 및 종료 버튼 처리

**관련 코드**
- `LoadMenu.cs`
- `GameManager.cs`
